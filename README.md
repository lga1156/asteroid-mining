# Asteroid Mining — ШРИ 2026 student template

Стартовый шаблон проекта для студенческого проекта в рамках **Школы разработки интерфейсов Яндекса (2026)**.

## О проекте

Студенты разрабатывают веб-приложение, посвящённое астероидам, сближающимся с Землёй. У каждого астероида имеется определенный набор характеристик, например диаметр, расстояние до него, а также сведения о полезных ресурсах, которые можно добыть на астероиде.

### Макеты

Для реализации приложения создан [Figma-макет](https://www.figma.com/design/X2dxm0rDqjo8Ee9I4dF1iE/%D0%A8%D0%A0%D0%982026?node-id=49001-34846&t=e1S45rriOfDys7pS-1).

Макет можно рассматривать как визуальный ориентир: можно реализовать его в точности, а можно местами делать иначе. Pixel-perfect вёрстка не нужна.

В макете используется [GravityUI](https://gravity-ui.com/), но в некоторых местах отрисованы нестандартные компоненты и элементы. Допустимо отходить от макетов в пользу GravityUI в целях экономии времени.

Самое главное — доступность контента и функционала.

### Общие требования

Пользователь может организовать миссию по добыче ресурсов с астероидов, просматривать историю и статус текущей миссии.

Для этого в приложении должны быть реализованы:

- список астероидов
    - отображение астероидов списком
    - отображение детальной информации об астероидах в модальном окне или на отдельной странице
    - отображение детальной информации об отдельном ресурсе (например, в выпадающем окне)
    - отображение статуса доступности астероида для добычи
    - добавление астероида в план миссии
    - удаление астероида из плана миссии
- план миссии
    - отображение списка астероидов, запланированных в очередную миссию
    - удаление астероида из плана
    - сводная информация о суммарном количестве ресурсов, которые будут добыты
    - подтверждение плана и создание миссии
- история миссий
    - отображение списка всех созданных миссий
    - отображение детальной информации о миссии, включая:
        - астероиды в миссии
        - сводный отчёт о ресурсах
        - прогресс выполнения или цепочку статусов
    - возможность перейти по ссылке к детальной информации о конкретной миссии

На всех страницах/экранах должны быть предусмотрены пустые (нет данных) и негативные (произошла ошибка) состояния.

Элементы астероидов и ресурсов должны поддерживать одинаковое взаимодействие на всех страницах: по клику или наведению мыши открывать модальное или выпадающее окно соответственно.

### Реализация проекта

Проект реализуется в рамках домашних заданий по 7 темам, рассматриваемым в ходе лекций:
* 1 - Асинхронность и веб-воркеры
* 2 - Типизация
* 3 - Nodejs
* 4 - React
* 5 - Перформанс
* 6 - Авто-тесты
* 7 - Инфраструктура

## Структура проекта

```
├── frontend/   # React SPA (Vite)

```

## Системные требования

- **Node.js** `22.12+`
- **npm** `10+`

Если используете [nvm](https://github.com/nvm-sh/nvm), в корне репозитория есть файл `.nvmrc` — достаточно выполнить `nvm use`.

## Зависимости

Из корня репозитория:

```bash
npm ci
```

Установит зависимости для всех workspaces (`backend`, `frontend`).

## Запуск

```bash
npm start
```

Запуск только frontend:

```bash
npm run start:frontend
```

Запуск только backend:

```bash
npm run start:backend
```

Сборка frontend для продакшна:

```bash
cd frontend && npm run build && npm run preview
```

Сборка backend для продакшна:

```bash
cd backend && npm run start
```
