# Тестовые сценарии

## Список астероидов

| Проверка                                                                  | Уровень         | Почему                                                        |
| ------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------- |
| Карточка показывает имя, диаметр, расстояние и ресурсы                    | Юнит компонента | Достаточно изолированно проверить отображение входных props   |
| Список создаёт карточку для каждого элемента                              | Юнит компонента | Проверяется локальная композиция без сети и браузера          |
| `GET /asteroids` возвращает страницу данных и учитывает пагинацию         | Юнит API        | Проверяется HTTP-контракт BFF при замоканных внешних сервисах |
| Пользователь видит данные, пришедшие через frontend → BFF → mock upstream | E2E             | Только сквозной тест подтверждает интеграцию всех слоёв       |

## Детальная информация

| Проверка                                                         | Уровень               | Почему                                                                   |
| ---------------------------------------------------------------- | --------------------- | ------------------------------------------------------------------------ |
| Открытый диалог показывает характеристики, массу, объём и пороги | Юнит компонента       | Проверяется ветвление представления ресурсов                             |
| Пустой список ресурсов показывает «Ресурсы не найдены»           | Юнит компонента       | Это локальное негативное состояние                                       |
| Кнопка закрытия вызывает `onClose`                               | Юнит компонента + E2E | Юнит фиксирует контракт callback, E2E — реальное закрытие portal-диалога |

## Классификация ресурсов

| Проверка                                                 | Уровень         | Почему                                            |
| -------------------------------------------------------- | --------------- | ------------------------------------------------- |
| Вид ресурса выбирает тему `utility` / `warning` / `info` | Тест в памяти   | Это чистое отображение discriminated union в тему |
| Badge получает вид ресурса и отображает символ           | Юнит компонента | Проверяется доступный DOM-контракт компонента     |

## Добыча

| Проверка                                                                     | Уровень       | Почему                                                         |
| ---------------------------------------------------------------------------- | ------------- | -------------------------------------------------------------- |
| Payload содержит непустой массив UUID v7                                     | Тест в памяти | Чистая валидация быстрее и точнее HTTP-теста                   |
| `POST /mine` принимает валидный запрос и отклоняет `{}`/пустой массив        | Юнит API      | Проверяются middleware и контроллер через реальный Express app |
| Пользователь добавляет цель, запускает добычу, видит loading и подтверждение | E2E           | Сценарий пересекает store, роутинг, mutation и BFF             |

## Навигация

| Проверка                            | Уровень         | Почему                                  |
| ----------------------------------- | --------------- | --------------------------------------- |
| Шапка содержит ссылки трёх разделов | Юнит компонента | Состав меню — локальный контракт        |
| Ссылка открывает экран статуса      | E2E             | Проверяется реальный клиентский роутинг |

## Визуальная стабильность

| Проверка                                             | Уровень     | Почему                                                              |
| ---------------------------------------------------- | ----------- | ------------------------------------------------------------------- |
| Карточка, диалог и шапка совпадают с эталонами       | Скриншотный | Геометрию и стили надёжнее фиксировать изображением                 |
| Полная страница совпадает при замаскированном canvas | Скриншотный | Динамический звёздный фон исключён, стабильный контент сравнивается |

Тесты не дублируют внутренние детали: unit-проверки фиксируют локальные контракты, API-тесты — HTTP BFF, E2E — только ключевые пользовательские цепочки, visual — внешний вид.
